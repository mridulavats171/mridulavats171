## 🚀 What I've Built (Production Work)

### 📺 OTT & Real-Time Streaming Platform
- Built backend for an **M3U-based OTT platform** serving **thousands of movies, series, and live channels**
- Designed **EPG (Electronic Program Guide)** pipelines with daily refresh across hundreds of channels
- Integrated **Ant Media Server** & **FFmpeg** for live and on-demand video processing (HLS/M3U8)
- Built **TV app APIs** with search, pagination, and device-specific delivery (Roku, Fire TV, mobile)
- **Impact:** Restructured Redis from flat lists to **sorted sets** — cut API response time from **seconds → milliseconds** for paginated content at scale. Public reconstruction: [redis-catalog-pagination](https://github.com/mridulavats171/redis-catalog-pagination)

### 💳 Payment & Subscription Systems
- Integrated **Stripe**, **PayPal**, and **NMI** payment gateways for multi-tenant SaaS billing
- Built subscription flows: trial periods, mid-cycle plan switching, prorated charges, and invoice scheduling
- Handled **webhook + API dual processing** for reliable payment state management
- Implemented safeguards against duplicate charges, invalid billing cycles, and edge cases in org-level billing

### 🔐 OAuth2, OpenID Connect & Social Integrations
- Integrated **Facebook Graph**, **Google/YouTube APIs**, **Twitter/X**, and **Instagram** via OAuth2
- Built secure auth flows distinguishing **OAuth2 (resource access)** vs **OIDC (identity verification)**
- Implemented **Instagram Live streaming** via Connect API with stream lifecycle management
- Handled social account linking, disconnect flows, and permission-based media publishing

### ⚡ Performance & Data Layer
- Optimized **Redis**, **MySQL**, **PostgreSQL**, and **MongoDB** for high-traffic read-heavy workloads
- Redesigned caching strategy when pagination alone couldn't fix in-memory bottlenecks
- Applied database constraints, query tuning, and API-level pagination for TV and web clients

### 🏗 Microservices (Personal Projects)
- Built a **microservices architecture** with separate User, Rating, and Hotel services
- Configured inter-service communication, config management, and modular Spring Boot services
